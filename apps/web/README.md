# @10spilot/web

Next.js 16 (App Router, Turbopack, Tailwind CSS v4) frontend for 10sPilot.

```bash
pnpm --filter @10spilot/web dev    # http://localhost:3000
pnpm --filter @10spilot/web build
```

Environment variables: see the repo root `.env.example` (`NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_APP_URL`).
